# Teste Multiplayer - Godot 4

Projeto de demonstração e template modular de **Lobby, Chat e Gerenciador de Rede Multiplayer** pronto para produção na Godot 4.

## 📦 Pacote Plug-and-Play

Todo o sistema multiplayer está empacotado na pasta [`multiplayer/`](./multiplayer/):

- Para instruções detalhadas de como copiar e utilizar este pacote em qualquer outro jogo, consulte o **[README do Módulo Multiplayer](./multiplayer/README.md)**.

## 🚀 Executando este Projeto

1. Abra este projeto na Godot 4 (4.0+ / 4.6+).
2. Execute o projeto (`F5`).
3. Para testar multiplayer localmente, rode duas instâncias (ou vá em **Debug > Customize Run Instances...** e marque 2 instâncias):
   - Uma como **Host**
   - Outra como **Join** (`127.0.0.1`)
